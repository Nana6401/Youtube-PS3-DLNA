# Youtube-PS3-DLNA
a lil vibecoded ps3 youtube client that works even with non modded consoles !

(just a quick thing im adding here incase here it will be recognized as a video server so go in the video tab in your ps3 menu and click on the server alr thanks :D).

basically from my understanding it creates a server that the ps3 can access then uses a youtube DATA v3 api key to access content do searches and other stuff and then uses ffmpeg to translate whatever youtube spits out into a watchable stream that the ps3 can read and render

heres what you will need : 
1) a PC
2) a PS3
3) a youtube data api v3 key (its free so you shouldn't need to pay)
4) the latest version of python
